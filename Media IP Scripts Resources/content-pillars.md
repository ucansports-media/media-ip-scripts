# Content Pillars — UCAN Media IP

*Source: content-plan-source.docx. Read this before drafting any new script or batch of scripts.*

There are 4 content pillars. Every script belongs to exactly one. Each week, one script per pillar per page (football, cricket, racket) — **4 scripts × 3 pages = 12 scripts/week**.

## The 4 Pillars

1. **Player Aura** — A player's trajectory and why they mattered. Sub-angles: career-defining moments, underrated/forgotten players, "what if," rising players.
2. **Rivalries** — Team or player rivalries.
3. **Past Tournaments / Team Content** — Event-driven, looking back at a tournament or match. Sub-angles: tactical explainers, kit and culture.
4. **League Fun Content** — Top 5s, past-season performances, numbers/records, debate prompts, reactive content, tactical explainers.

Per pillar, per week: 3 content pieces (one per page) —
- **Player Aura**: Football (present players) · Cricket (legends, present players) · Racket (tennis, badminton players)
- **Rivalries**: Football · Cricket · Racket
- **League Fun Content**: Football · Cricket · Racket
- **Past Tournaments**: Football · Cricket · Racket

## Weekly Cadence (per page)

This is the full publishing calendar, including non-script content — only Mon/Wed/Fri/Sun are talking-head scripts (this workstation's scope). Tue/Thu/Sat are memes/UGC, out of scope here.

| Day | Content |
| :---- | :---- |
| Mon | Player Aura |
| Tue | Memes / UGC |
| Wed | Team/Player Rivalries |
| Thu | Memes / UGC |
| Fri | Past Tournaments / Team Content |
| Sat | Memes / UGC |
| Sun | League Fun Content |

**Note:** this daily cadence (one pillar per weekday) is the original content-plan design. It doesn't fully match the "shoot once a week on Tuesday, 4 scripts per page" cadence Adit described more recently — worth confirming with Adit which is current before relying on either for scheduling assumptions. The 4-pillar breakdown and the 12-scripts/week total are consistent across both.
