# Setup Guide — UCAN Media IP Scriptwriter

A simple, one-time setup. Takes about 5 minutes.

## What you need

1. **Claude Code** — install it from [claude.com/claude-code](https://claude.com/claude-code) if you don't have it.
2. **GitHub Desktop** — download from [desktop.github.com](https://desktop.github.com/). This is the easy way to get the project files onto your computer without using any command-line commands.
3. **A GitHub account** — free, sign up at [github.com](https://github.com/join) if you don't have one. Send Adit your username so he can give you access.

## Steps

1. **Wait for the invite.** Adit adds you as a collaborator on the repo. You'll get an email from GitHub — click "View invitation" and accept it.

2. **Clone the repo with GitHub Desktop:**
   - Open GitHub Desktop → File → Clone Repository
   - Paste this URL: `https://github.com/ucansports-media/media-ip-scripts`
   - Pick a location on your computer (anywhere is fine — Desktop is simplest) and click Clone.

3. **Open the folder in Claude Code:**
   - Open Claude Code
   - Open the folder you just cloned (the one called `media-ip-scripts`)

4. **You're set up.** From here, everything happens by talking to Claude in that folder. It automatically pulls the latest scripts, rules, and skills every time you open a session — you never need to touch git or GitHub again.

## How to use it

Just type these commands (or ask in plain English and Claude will know what to do):

| Command | What it does |
| :---- | :---- |
| `/media-ip-research` | Researches this week's topic ideas for football, cricket, and racket |
| `/media-ip-scriptwriter` | Drafts a script (Claude uses this automatically when you ask for a script) |
| `/media-ip-compile` | Combines a week's finished scripts into one branded PDF |
| `/media-ip-captions` | Generates Instagram caption + hashtags + tags for finished scripts |
| `/media-ip-learn` | Logs a script/reel you liked, so it can be considered for the house voice |

If you're ever unsure what to do, just ask Claude directly — e.g. "what should I do next" or "draft the football scripts for this week." It knows the full workflow.

## If something looks wrong

If a script doesn't match the established voice, or a rule seems off, just say so in the session — Claude will explain its reasoning or fix it. Nothing here is set in stone; it's meant to improve as the team uses it.
