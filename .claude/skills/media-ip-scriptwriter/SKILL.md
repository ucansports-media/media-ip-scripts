# Media IP Scriptwriter

Writes 45–60 second talking-head scripts for UCAN Sports' media IP across football, cricket, and racket sports (tennis, badminton). The patterns below were extracted directly from **Month 1's produced scripts** (`Media IP Scripts Resources/past-scripts/`) — two real shoots, each covering all 4 content pillars × 3 sports (12 scripts each). This is not a generic template.

**Before drafting, always read** `Media IP Scripts Resources/content-pillars.md` — every script must map to exactly one of the 4 pillars (Player Aura, Rivalries, Past Tournaments/Team Content, League Fun Content) — and `Media IP Scripts Resources/ucan-brand-context.md` for who UCAN actually is. UCAN is a Mumbai recreational sports league platform (cricket, football, racket sports) — these Media IP scripts are broader sports storytelling, not about UCAN's own leagues, but should still read as credible sports content from a real sports organization, not a generic content farm.

There are **two live house voices**. Ask which one fits the topic/mood if it's not obvious, or default to the beat-table style (it's the more structured, easier-to-shoot default) when there's no clear signal either way.

---

## Voice 1: The Beat-Table Style (Shoot 2)

Timed, with an explicit visual cue per beat. 100–150 words, 42–60 seconds. Can run in English or Hinglish (mix Hindi/English freely — see the Kohli and Tendulkar examples).

| Beat | Job |
|---|---|
| HOOK | Bold claim, name-drop, or scene-setting line. Establish who/what immediately. |
| SET-UP | The stakes — context that makes the story matter. |
| THE STORY | The actual telling — what happened, in sequence. |
| THE TWIST | The turn — the moment that recontextualizes everything before it. |
| THE LINE | One closing line that lands the theme, usually followed by a direct-address comment prompt ("Tell us in the comments," "Drop your score"). |

Each beat has a `VISUAL:` cue describing what's on screen — write these alongside the voiceover line, not as an afterthought.

**Example (Football · Player Aura, from Shoot 2):**
> HOOK: "Ferran Torres. At Barcelona, he was never guaranteed a place."
> SET-UP: "With one year left on his contract, Ferran asked to leave. And Barcelona let the Shark swim away."
> THE STORY: World Cup final, 106th minute, Torres scores, Spain champions.
> THE TWIST: Move to PSG — brace on debut, Champions League hat-trick.
> THE LINE: "Because sometimes a player isn't finished. Sometimes he's just finished with you. [...] Did Barcelona get this one wrong? Tell us in the comments."

**Pattern notes:**
- Every script ends on a comment-bait question or prompt — this is consistent across all 12 Shoot 2 scripts, not optional.
- Hinglish scripts (cricket, in this batch) mix languages naturally mid-sentence rather than alternating whole sentences — e.g. "Target sirf 160 tha, lekin aakhri 8 balls mein 28 runs chahiye the."
- "League Fun / Top 5" scripts drop the 5-beat structure for a straight countdown (HOOK → 5 → 4/3 → 2 → 1), each number a mini-scene with its own visual cue.

## Voice 2: The Cinematic Style (Shoot 1)

Dramatic, second-person or declarative narration. No visual-cue table, no explicit beat labels — four unlabeled timed segments (roughly 0:00–0:08 / 0:08–0:22 / 0:22–0:35 / 0:35–0:45), each 3–6 short punchy lines. Every script hits exactly 45 seconds. Runs in English or Hindi (not mixed mid-sentence like Voice 1's Hinglish — each script is fully one language).

**Example (Football · Player Aura, from Shoot 1):**
> "Imagine walking into the Santiago Bernabéu. Twenty years old. The heaviest shirt in football history resting on your shoulders. [...] For Jude Bellingham… it was just an invitation."

**Pattern notes:**
- Opens on scene-setting or a direct challenge to the viewer's imagination ("Imagine…", "Socho…", "For decades, women's badminton was a fortress…").
- Short line breaks even mid-sentence for pacing — write it the way it should be read aloud, not as prose paragraphs.
- Closes on a thematic, often aphoristic line — no comment-bait question (unlike Voice 1). The line itself is the hook for sharing/rewatching, not a prompt.
- Treats specific stats/records as claims to verify, not facts to invent — Shoot 1's own cover note flags this: "highly specific stats (exact weeks at world No. 1, precise transfer-era claims, odds figures) should be treated as draft and checked against two sources before shoot day."

## Third Reference: The 39-Reel Corpus (Hook Craft)

`Media IP Scripts Resources/reference-corpus/7 Min Football Reels Complete Transcripts - Final.docx` is a 39-script Instagram football reel corpus (166–326 words each, same 5-beat HOOK/SET-UP/STORY/TWIST/LINE shape as Voice 1 above, but for UCAN's separate short-form sports-reel product — a different, more compressed, dramatic-commentary register than either Media IP voice). Adit deliberately included it here as a **hook-craft reference only**, not as this IP's own voice. Pull from it for hook-writing technique (how it opens cold on a bold claim, how it escalates into the twist) rather than copying its sentence-level tone.

## Shared Rules (both voices)

- **Language**: English, Hindi, or Hinglish per script — driven by the sport/pillar/topic, not fixed. Cricket content in both shoots leans Hindi/Hinglish; football and racket lean English. Don't assume — check what similar past scripts for that sport did.
- **Runtime**: 45 seconds is the target across both voices (Shoot 2 ranges 42–60s; Shoot 1 is consistently 45s exactly). Don't write scripts that read at 80+ seconds — verify word count against pace (~2.2–2.6 words/sec) before finalizing.
- **Fact-checking**: verify specific stats (records, exact dates, rankings, odds) against at least one source before treating a draft as final — don't invent precision.
- **One script, one pillar, one page** — never blend pillars or write a script that could apply to more than one sport.
