# Media IP Captions

Produces posting copy for finished scripts — normally run after a shoot week's scripts are finalized (post-`/media-ip-compile`, once footage is shot and ready to post), so captions are ready the moment Adit needs to post, instead of him writing them from scratch each time.

## Format (exact — this is Adit's established style, don't deviate)

Three lines per script, in this order:

1. **The basic caption** — one to two short sentences capturing the hook or theme of the script. Can include a single relevant emoji. Written to stand alone as the Instagram caption text, not a restatement of the script.
2. **The hashtag line** — a single space-separated line of hashtags. Mix brand tags (`#UCAN #UCANSports`), the sport/league (`#Football`, `#PremierLeague`, `#Cricket`, `#IPL`, `#Badminton`, etc. — whatever's actually relevant to that script), and a format tag (`#FootballReels`, `#CricketReels`, etc.). 5–7 hashtags is the right range, not a wall of tags.
3. **The tags line** — a bracketed, comma-separated list of broader keyword tags: `[Tag One, Tag Two, Tag Three, ...]`. These are topic/SEO keywords, not hashtags — broader terms than the hashtag line (e.g. "Football History" rather than "#FootballReels").

**Reference example (Adit's own):**
> The title wasn't safe until the final whistle. One last kick could change everything. ⚽️
>
> #UCAN #UCANSports #PremierLeague #Football #FootballReels
>
> [UCAN Sports, UCAN, Premier League, Football, Football History]

## Steps

1. Find the target: a specific script Adit names, or every script in the most recent (or named) dated folder.
2. For each script, read it fully — the caption should reflect the actual hook/theme of that specific script, not a generic sports caption.
3. Produce the 3-line block above, per script, clearly labeled with the script's title/filename so it's easy to match caption to script.
4. Save the output alongside the scripts: `<dated folder>/captions.md`, one block per script.
5. Commit and push per the Team Sync rule.

## Platform notes

This format is **Instagram-specific** (caption + hashtags + Instagram-style tags). YouTube uses a different structure entirely (title, description, a separate tags field in YouTube Studio — no hashtag wall the way Instagram uses one). If Adit wants YouTube posting copy generated too, that needs its own format spec from him first — don't improvise YouTube titles/descriptions against the Instagram format above.
