# Media IP Learn

Lets anyone on the team submit a script/reel they liked as a reference, with notes on what specifically to take from it.

## Steps

1. Ask for: the reference itself (pasted text, a link, or an attached file) and **what specifically they like about it** — a hook technique, a pacing choice, a line structure, anything concrete. Don't accept a vague "this is good" with nothing actionable.
2. Write a new file to `Media IP Scripts Resources/learned-references/YYYY-MM-DD_<short-slug>.md` containing:
   - Date
   - The reference (text, link, or note of the attached file's location)
   - What was liked about it
   - Your own one-line read on what concrete change this might suggest for the skill
3. Commit and push per the Team Sync rule, so it's visible to the whole team right away.
4. If it's clear the change should actually be applied to `media-ip-scriptwriter`, `media-ip-compile`, `media-ip-captions`, or `CLAUDE.md`, discuss it with whoever's in the session and make the edit as you normally would — no special approval process. Use judgment: a reference that's genuinely just a personal preference or a one-off doesn't need to become a permanent house rule.

## Reviewing the log

If asked to "review the learned references" or similar, list everything in `learned-references/` with a one-line summary each.
